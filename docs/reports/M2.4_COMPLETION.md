## 4. Model and integrity

- **Templates:** versions are immutable (a trigger refuses even the migration owner) and strictly parsed before use. The runtime role has `SELECT` only. A malformed effective version refuses new drafts.
- **Drafts:** one `DRAFT` per candidacy (partial unique index), pinned to its template version, with immutable references.
- **Sections:** one row per section, a size-bounded JSON object, a server-set completion status, and an optimistic version that a trigger requires to rise by exactly one.
- **No hard deletion:** the runtime role has no `DELETE` or `TRUNCATE`, and triggers refuse them too.

Draft answers overwrite in place, so earlier draft values aren't kept. Audit records each save's section, status, and version, and never an answer.

## 5. Commands and evidence

Commands: `begin_application_draft`, `save_application_section`, and `assist_save_application_section`. Queries: `queryApplicationOverview` and `queryApplicationSection`, which return exact projections `candidate.application_overview.v1` and `candidate.application_section.v1`.

`tests/integration/applications/application-draft.test.ts` proves:

- **Idempotency:** the same key replays once, and the same key with a different request is rejected.
- **Concurrency:** lock-barrier races produce one applied save and one `STALE_VERSION`; concurrent begins create one draft.
- **Atomicity:** an audit failure rolls back the save and its receipt.
- **Nondisclosure:** another candidate gets the same result as an unknown reference, and an answer canary doesn't appear in audit rows.
- **Input safety:** mass assignment, malformed JSON, oversized input, unknown sections, and bad keys change nothing.
- **Authority:** manager, HR, recruiter, and administrator are denied all three commands.
- **Reads:** a GET creates no draft or audit event.

**Auditors** are covered only at the catalog level (`auditor grants are read or export only`), because the real organization test harness has no audit-assignment support. **The assisted path** is exercised through the test-harness actor, since no real role can reach it.
